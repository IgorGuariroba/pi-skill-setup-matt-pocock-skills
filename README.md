# pi-skill-setup-matt-pocock-skills

[![Pi Package](https://img.shields.io/badge/pi--package-skill-blue)](https://github.com/IgorGuariroba/pi-skill-setup-matt-pocock-skills)

**setup-matt-pocock-skills** skill for the **[Pi coding agent](https://pi.dev)**, adapted from Matt Pocock's Engineering Skills.

> Configure this repo for the engineering skills: set up its issue tracker, triage label vocabulary, and domain doc layout. Run once before first use of the other engineering skills.

---

## Installation

Install directly into Pi using `pi install`:

```bash
pi install git:github.com/IgorGuariroba/pi-skill-setup-matt-pocock-skills
```

Or clone into your local/global skills directory:

```bash
# Global Pi skills directory:
git clone https://github.com/IgorGuariroba/pi-skill-setup-matt-pocock-skills.git ~/.pi/agent/skills/setup-matt-pocock-skills

# Or Agent Skills standard path:
git clone https://github.com/IgorGuariroba/pi-skill-setup-matt-pocock-skills.git ~/.agents/skills/setup-matt-pocock-skills
```

---

## Usage

Trigger it explicitly in your session:

```text
/skill:setup-matt-pocock-skills
```

Or let Pi automatically route to it based on conversation context and need.
